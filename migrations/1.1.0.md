# Migración a 1.1.0 — skill-installer y el sistema de actualización

> Instrucciones para el agente que actualiza una instalación del coach. Se ejecutan desde el repositorio siguiendo `UPDATE.md` (su paso 4 define el vocabulario y las reglas). Este archivo no se copia a la carpeta del usuario.

Esta versión incorpora la skill `skill-installer` y estrena el marcador `AIOS/VERSION.md` (que fija el propio proceso de actualización, no esta migración).

## Añadido

- `AIOS/skills/skill-installer.md` — **ruta movida**: el repositorio ya no contiene este archivo (desde la 2.0.0 la skill vive en `AIOS/skills/skill-installer/SKILL.md`). Salta esta copia: la migración 2.0.0 la crea directamente en su forma nueva.
